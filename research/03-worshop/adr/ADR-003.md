# ADR-0003: Choose SAST, DAST and SCA
Status: Accepted (2026-11-27)
Context: Choose a best fit SAST, DAST and SCA based on the env and setup complexity 
Options: SAST: (1.A) SemGrep (1.B) GitHub CodeQL (1.C) SonarQube | DAST: (2.A) ZAP | SCA: (3.A)Snyk Open Source (3.B) Trivy (3.C) Aikido Security (3.D) SCA + SBOM
Decision: (1.A). Is simple to implement beacuse of yml rules if needed, wide choose in the devsecops industry and fast for commits with SARIF format. | (2.A) This is beacuase is the most used, the automation is simple and open source, but difficult to configure it | (3.D) this is beacuse it covers auditory, doesnt need re run a pipleine to found the vulnerbilities in the running app and a great spped generation using Syft + Grep
