# Sast
## What is
Static application security testing (SAST) automated analysis to find security vulnerabilities directly on the soruce code withpout executing it, a white box testing
### Tools
tool - analysis depth - speed ci/cd - custom rules - liscening - formats
SemGrep - medium to high - very fast - very easy (yaml) - open source - SARIF/JSON
GitHub CodeQL - very high - slower - complex (QL) - free for public open source repos - SARIF
SonarQube - medium to high - moderate - rigid (sonar type) - free open source community - JSON web api

link: https://www.ibm.com/think/topics/sast
